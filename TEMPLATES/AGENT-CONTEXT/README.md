# Agent context templates

The development-phase agent-context entries (B09) have logical destinations in the catalog;
no rendered variants are checked in. Render canonical, blank or synthetic-example files on
demand with `make docs-templates` (or `autodoc templates`) into ignored `build/TEMPLATES/`.
Apply the same ownership, metadata and freshness policy to an instantiated document as to other
human-owned records. An agent must not fabricate state, priorities, audit evidence or verification dates.
